# AI Interview Copilot

Fullstack assistant that compares a job description with resume content, then produces fit scores, missing skills, resume bullets, and interview questions.

## Run

```bash
npm install
npm run dev
```

Frontend: `http://127.0.0.1:5174`  
API: `http://127.0.0.1:4002`

## What It Shows

- React state and reporting UI.
- Node/Express scoring API.
- AI product thinking around feedback loops, explainability, and actionable output.
