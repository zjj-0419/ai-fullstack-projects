# Voice Agent Studio

Voice Agent Studio is a fullstack console for routing voice transcripts into AI actions, planning tool calls, reviewing quality guardrails, and persisting review decisions before automation runs.

## Features

- Session inbox with intent, confidence, latency, and review status.
- Detail view with transcript timeline, tool plan, and QA guidance.
- Live transcript analyzer that classifies intent and returns next actions.
- Create-session workflow that persists data to `server/data/sessions.json`.
- Tool-run simulation with completed or QA-blocked steps.
- Human review controls for approve/block/review states.
- Markdown report export generated by the backend.
- Node/Express API with validation, state mutation, and deterministic mock AI.

## Run

```bash
npm install
npm run dev
```

Frontend: `http://127.0.0.1:5176`  
API: `http://127.0.0.1:4004`

## API Smoke Test

Start the server first, then run:

```bash
npm run server
npm run test:api
```

The smoke test creates a session, runs the tool chain, updates review status, and verifies report generation.

## Key API Endpoints

- `GET /api/sessions`
- `POST /api/sessions`
- `GET /api/sessions/:id`
- `PATCH /api/sessions/:id/status`
- `POST /api/sessions/:id/run`
- `GET /api/sessions/:id/report`

## Interview Talking Points

- Demonstrates voice product thinking beyond a static chat UI.
- Shows how AI output can be routed through tool planning and human review.
- Includes backend persistence, API validation, mutable workflow state, and exportable artifacts.
- Clear place to replace mock routing with a real LLM, speech-to-text provider, or workflow engine.
