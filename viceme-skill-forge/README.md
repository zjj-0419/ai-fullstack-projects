# VoiceMe Skill Forge

AI-assisted Skill creation and publishing workflow for a voice creator product.

## Features

- React workspace for entering product, audience, and goal.
- Node/Express endpoint that generates a Skill README, publish checklist, and readiness score.
- Interview-friendly architecture that can be swapped from mock AI to OpenAI, Claude, or a private model.

## Run

```bash
npm install
npm run dev
```

Frontend: `http://127.0.0.1:5173`  
API: `http://127.0.0.1:4001`

## Talking Points

- Shows frontend product polish and backend API ownership.
- Connects directly to Skill creation and Skill publishing requirements.
- Demonstrates AI-assisted development without requiring paid API keys.
