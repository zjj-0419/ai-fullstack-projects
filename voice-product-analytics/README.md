# Voice Product Analytics

React + Node dashboard for AI voice product signals, creator segments, experiment opportunities, and AI-generated product recommendations.

## Run

```bash
npm install
npm run dev
```

Frontend: `http://127.0.0.1:5175`  
API: `http://127.0.0.1:4003`

## What It Shows

- Product metrics and segment analysis.
- Backend API ownership for analytics data.
- Practical AI product recommendations tied to user value.
